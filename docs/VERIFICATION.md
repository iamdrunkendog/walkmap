# 구현 및 검증 결과

검증일: 2026-09-08. macOS / Node.js 24.19.0 / 실제 Google Chrome의 데스크톱 1440×1000 및 모바일 390×844 화면을 사용했습니다.

## 전달 상태

실행 가능한 코드·로컬 환경설정·SQLite 서버 저장·한국어 화면·자동 검증·배포 파일을 작성했습니다. 로컬 서버는 `http://127.0.0.1:3000`에서 실행했습니다. **실제 네이버 지도 배경과 실제 SDK 위의 경로 편집 검증은 네트워크 차단 때문에 완료하지 못했습니다.** 전체 완료나 운영 배포 검증 완료로 해석하면 안 됩니다.

첨부 WalkMap 폴더와 `https://github.com/iamdrunkendog/walkmap.git`은 모두 비어 있었고 기존 AGENTS/README/구현/미반영 변경은 없었습니다. 첨부 폴더 안 `worktree/`에 해당 원격 저장소를 복제했습니다. ChatGPT 프로젝트의 AGENTS.md를 확인했고 동기화 참고 자료는 변경하지 않았습니다. 사용자가 언급한 예시 이미지는 전달된 폴더에 없었습니다.

소스는 GitHub `main` 브랜치에 전달할 준비를 마쳤고 공개 배포는 수행하지 않았습니다. 기존 파일을 초기화하거나 덮어쓰지 않았습니다. 검증 중 생성한 중간 코스는 정리했고, 명시적으로 `검증 예시`라고 이름 붙인 코스 한 개를 개인 계정에 남겼습니다. 이 코스는 추천 도보 경로나 실제 통행 가능한 코스를 뜻하지 않습니다.

## 자동 검증

`node --test tests/core.test.mjs`: **5개 테스트 통과, 실패 0**.

- 점 추가·삽입·이동·삭제와 이력/거리 복원
- 시간 계산·복제 독립성·잘못된 입력 및 위험 URL 거부
- API HUB 좌표와 네트워크/인증/한도/빈 결과 분류
- 서버 저장·재시작 복원·사용자 소유권·세션·Origin·충돌·삭제
- 저장 전후 객체 필드 순서가 달라도 같은 내용을 동일하게 인식하는 회귀 검사

`tests/browser.mjs`: **10개 흐름 체크 통과**, 브라우저 런타임 오류 0. [기계 판독 결과](browser-results.json).

`tests/live-check.mjs`: TLS 검증을 해제하지 않고 실행했습니다. SDK/인증 HTTP 200 및 지도 리소스 인증서 실패를 기록했습니다. [실제 연결 기록](live-results.json).

`tests/secrets-check.mjs`: 알려진 실제 인증 값 4개에 대해 Git 노출 0건. 실제 값은 보고서·출력에 기록하지 않습니다. 배포/커밋 전에 다시 실행할 수 있습니다.

별도 빌드가 필요 없는 기본 JavaScript 모듈과 Node 내장 서버/SQLite 구성입니다. 서버와 브라우저 모듈의 구문 검사 및 실제 실행을 확인했습니다. Docker 빌드, 운영 HTTPS, 대규모 부하, 실제 모바일 장치 검증은 하지 않았습니다.

## 발견하고 수정한 문제

1. SDK의 콜백 시점에서 전역 객체 생성이 끝나기 전 초기화를 시도함 → 스크립트 실행 완료 후 초기화.
2. SDK의 인증·스타일 요청이 CSP에서 차단됨 → 공식 사용 호스트를 허용하고 외부 요청을 HTTPS로 승격.
3. 검색 선택 안내가 그리기 도구를 덮음 → 선택 시 검색 패널을 접고 결과 닫기 제공.
4. 경로 점 위를 클릭하면 방문 위치를 선택하지 못함 → 방문 선택 모드에서 경로 점도 위치로 사용.
5. 필드 순서 때문에 저장 후 미저장 표시가 유지됨 → 안정적인 내용 비교와 회귀 검증 추가.
6. 지도 마커가 모바일 도구 버튼을 가림 → 지도 내부 레이어를 독립적으로 제한.
7. 지도 가장자리 방문 라벨 잘림 → 화면 안쪽으로 라벨 위치 보정.
8. 저장되지 않은 기존 초안이 새 편집으로 덮일 수 있음 → 이전 초안 복원/삭제 선택 전 변경 보호.

## 남은 설정 및 제한

- 네트워크 관리자에게 네이버 지도 리소스 `nrbe.map.naver.net` 차단 상태 확인과 필요한 허용을 요청해야 합니다. 키 재신청은 필요하지 않습니다. 보안 필터/DNS/TLS 우회 코드는 넣지 않았습니다.
- 허용 후 `tests/live-check.mjs` 및 실제 네이버 지도 위의 작성·드래그·삽입·취소·저장 재검증이 필요합니다.
- 운영 도메인을 Maps 허용 URL에 등록해야 합니다. 서버 영구 디스크와 HTTPS 리버스 프록시, 운영 계정/비밀번호를 준비해야 합니다. 단일 서버·소규모 운영 구성입니다.
- API HUB 반환 데이터의 장기 보관 약관은 확정하지 못해 검색 결과 저장을 제외했습니다. [확인 자료 및 미확정 항목](NAVER.md).
- 경로 편집점 최대 2,000개, 방문 장소 100개, 이력 100단계. 장거리 경로의 대규모 마커 성능은 검증하지 않았습니다.
- 공개 공유·자동 길찾기·공동 편집·위치 추적·사진/리뷰 수집·이미지/PDF 출력은 범위 밖입니다.
