# WalkMap

네이버 지도에 직접 그린 도보 경로와 방문 장소·체류시간을 저장하는 개인/소규모 포토워크 앱입니다. 한국어 PC 편집 및 휴대폰 열람을 지원합니다.

## 시작하기

Node.js **24 이상**이 필요합니다. 런타임 외 설치 의존성이 없으며 별도 빌드가 필요하지 않습니다.

```sh
cp .env.example .env
# .env를 로컬 편집기로 열어 설정합니다. 이미 .env가 있다면 덮어쓰지 마세요.
node --env-file-if-exists=.env manage.mjs add-user myname
# 화면에 표시되지 않는 비밀번호를 12자 이상 입력합니다.
node --env-file-if-exists=.env server.mjs
```

이 작업 환경에서는 인증 정보를 `.env`에 설정했고 초기 개인 계정 `walkmap`을 만들었습니다. 초기 비밀번호는 Git에서 제외된 `data/initial-login.txt`에만 있습니다. 아래 명령으로 비밀번호를 바꾸면 기존 로그인 세션은 모두 만료됩니다.

```sh
node --env-file-if-exists=.env manage.mjs reset-password walkmap
```

설정된 접속 주소: **http://127.0.0.1:3000**. 이 환경의 Maps 인증 검사에서 `127.0.0.1`은 성공했지만 `localhost`는 실패했습니다. 브라우저 주소와 `APP_ORIGIN`을 일치시켜 주세요.

이 Mac에서 `node` 명령을 찾을 수 없으면 다음 런타임을 사용할 수 있습니다.

```sh
export PATH="/Users/ryankim/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH"
```

## 환경변수

`.env.example`에는 변수명과 빈 값만 있습니다. 실제 `.env`, 계정 및 DB는 Git에서 제외됩니다. `.env`는 파일 권한 600을 유지하세요.

| 변수 | 용도 |
| --- | --- |
| `NAVER_MAPS_CLIENT_ID` | Maps 브라우저 SDK용 공개 식별자. 로그인 후 `/api/config`에서 이 값만 전달 |
| `NAVER_MAPS_CLIENT_SECRET` | Maps 서버 API용 비밀키. 현재 수동 경로 앱에서는 사용하지 않으며 브라우저로 전달하지 않음 |
| `NAVER_SEARCH_CLIENT_ID` | **API HUB** 지역 검색 서버 인증용 ID |
| `NAVER_SEARCH_CLIENT_SECRET` | **API HUB** 지역 검색 서버 전용 비밀키 |
| `APP_ORIGIN` | 정확한 접속 출처. 로컬은 `http://127.0.0.1:3000`, 운영은 실제 HTTPS 출처. 끝에 `/`를 붙이지 않음 |
| `HOST` | 기본 `127.0.0.1`. 컨테이너는 `0.0.0.0` |
| `PORT` | 기본 `3000` |
| `DATA_DIR` | SQLite 데이터 디렉토리. 기본 `./data`, 운영은 영구 로컬 볼륨 지정 |
| `NODE_ENV` | 운영은 `production`. HTTPS 출처 필수, Secure 쿠키/HSTS 적용 |

Maps Application에서 Dynamic Map을 선택하고 실제 서비스 도메인을 Web 서비스 URL에 등록해야 합니다. API HUB Application에는 지역 검색 API가 선택되어 있어야 합니다. 콘솔 등록 목록 자체는 이 작업에서 조회하지 못했으며, 성공한 요청만 확인했습니다.

## 사용하는 방법

1. 장소를 검색하고 결과를 선택하면 지도만 이동합니다. 지도 이동·확대는 검색을 발생시키지 않습니다.
2. **그리기 시작** 후 지도에 점을 차례로 찍고 **완료**합니다. 그리는 중에는 지도 끌기를 끕니다. **취소**는 시작 전 경로로 돌립니다.
3. 경로 점을 끌어서 이동합니다. 선의 **＋**로 중간 점을 넣습니다. 점을 클릭하면 삭제 버튼이 나타납니다. 경로 편집 탭에서는 좌표로 이동할 수도 있습니다.
4. **실행 취소/다시 실행**은 경로·방문·코스 필드 변경을 되돌립니다. 입력란 밖에서 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z를 사용할 수 있습니다. 이력은 최대 100단계이며 재접속 후에는 유지하지 않습니다.
5. **장소 추가** 후 지도를 클릭합니다. 이름·방문 순서·체류시간·메모·직접 확보한 공유 링크를 입력합니다. 방문 위치 변경은 경로 편집점과 별개입니다.
6. **코스 저장**은 서버 SQLite에 저장합니다. 새로고침 후 **내 코스**에서 이름·지역·태그로 찾아 다시 엽니다. **코스 복제**는 독립된 새 코스 초안을 만들며 저장해야 서버에 등록됩니다.
7. 삭제는 확인 후 진행합니다. 다른 창에서 먼저 수정한 경우 저장/삭제를 거부해 오래된 내용으로 덮어쓰지 않습니다. 충돌한 편집 내용은 **코스 복제**로 별도 저장할 수 있습니다.

비밀값 검사: `node tests/secrets-check.mjs`.

거리는 구면거리 공식을 사용한 **직접 그린 선의 길이**입니다. 실제 보도·통행 가능 여부를 판단하지 않습니다. 보행시간은 거리 ÷ 사용자 속도이며 체류시간을 더해 전체 예상시간을 계산합니다. 각 표시 시간은 분 단위로 올림하므로 화면의 올림된 항목 합계와 전체 올림값 사이에 1분 차이가 날 수 있습니다. 실제 경로 안전성과 이동시간은 현장에서 확인하세요.

방문 라벨은 화면 위치가 겹치면 번호 마커로 줄여 표시하며, 전체 이름과 체류시간은 방문 목록에서 항상 확인할 수 있습니다.

## 저장·계정·보안

- 서버 SQLite가 관리용 원본입니다. 계정별 소유자 조건을 모든 코스 조회·수정·삭제에 적용합니다. 공개 회원가입·공개 공유 URL은 없습니다. 운영자가 CLI로 필요한 계정을 추가합니다.
- 비밀번호는 개별 salt+scrypt로 보관합니다. 세션은 무작위 토큰의 해시를 DB에 보관하며 HttpOnly·SameSite=Strict 쿠키, 7일 만료를 사용합니다. 운영 쿠키에는 Secure를 추가합니다.
- 변경 요청에 정확한 Origin을 요구합니다. 로그인과 검색에는 단일 서버 기준 요청 제한을 적용합니다.
- 브라우저 localStorage는 **사용자별 미저장 초안 1개**의 보조 저장소입니다. 동기화 저장이 아닙니다. 저장 실패, 새로고침, 세션 만료 후 같은 계정으로 로그인하면 복원할 수 있습니다. 공용 컴퓨터는 사용 후 로그아웃하세요. 명시적으로 변경을 버리거나 로그아웃하면 해당 임시저장을 삭제합니다.
- 서버 저장 중에는 잠시 편집을 막습니다. 실패해도 코스 내용은 유지합니다. 저장된 코스는 버전 검사로 여러 탭의 덮어쓰기를 막지만 공동 편집은 지원하지 않습니다.
- 정적 파일은 명시한 네 파일만 제공하며 `.env`, DB, 테스트, 문서는 웹 경로로 제공하지 않습니다.
- 검색 API 데이터는 응답 후 브라우저 메모리에만 잠시 표시합니다. 서버 캐시, DB, 임시저장에 넣지 않습니다. 검색의 업체 URL도 전달·자동 저장하지 않습니다.
- 코스 DB는 허용된 필드만 저장합니다. 경로 좌표는 지도에서 직접 지정하고 방문 정보에는 `source: user`를 기록합니다. API 결과를 자동으로 방문 정보로 변환하지 않습니다. 수동 입력 여부를 악성 클라이언트로부터 법적으로 보증하는 장치는 아닙니다.

## 검증

```sh
node --test tests/core.test.mjs
```

경로 변경 및 이력 복원, 시간 계산, 복사본 독립성, 입력/링크 검증, API HUB 오류 분류, 서버 재시작 복원, 사용자 격리, 세션/출처 검사, 버전 충돌 검사를 실행합니다. 임시 DB는 테스트 종료 후 제거합니다.

선택적 Chrome 검증은 Playwright가 필요합니다. 런타임 의존성과 분리된 개발 도구입니다. 로컬 서버 실행 후:

```sh
npm install --no-save playwright
WALKMAP_CHROME='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
  node --env-file=.env tests/browser.mjs
```

브라우저 검증은 `data/initial-login.txt`를 사용하거나 `WALKMAP_TEST_USERNAME`/`WALKMAP_TEST_PASSWORD` 환경변수로 테스트 계정을 지정합니다. 테스트용 계정을 사용하세요. 서버에 검증용 코스가 생성됩니다. 지도 SDK만 테스트 좌표판으로 대체하고 API HUB 검색·서버 저장은 실제로 호출합니다. `tests/map-fixture.js`는 서버에서 제공하지 않으며 앱에서 사용할 수 없습니다. 상세 결과는 [검증 기록](docs/VERIFICATION.md)을 확인하세요.

## 네이버 연결 상태 및 자료 이용 조건

[공식 연결·데이터 정책 확인 기록](docs/NAVER.md)을 참고하세요. 실제 API HUB 검색과 Maps 인증은 성공했습니다. 이 네트워크에서는 **Fortinet Secure DNS가 `nrbe.map.naver.net`을 차단**해 실제 지도 배경 표시와 실제 SDK 위의 편집은 검증하지 못했습니다. 네트워크 관리자가 정상 지도 리소스 연결을 허용한 후 실제 브라우저에서 재검증해야 합니다. 앱의 TLS 검증을 해제하거나 보안 필터를 우회하는 코드는 포함하지 않습니다.

API HUB 검색 결과의 장기 저장·재사용 권한을 확인할 수 있는 서비스별 최신 약관 본문은 확보하지 못했습니다. 따라서 검색 결과 저장 기능은 구현하지 않았습니다. 이 조건이 필요한 후속 기능은 NAVER Cloud의 적용 약관 또는 서면 답변으로 허용 범위를 확인한 후 추가하세요.

## 배포 준비

이 앱은 서버와 영구 디스크가 필요합니다. 정적 호스팅만으로 실행할 수 없습니다. 추가 계정이나 유료 서비스를 자동으로 만들지 않았고, 공개 배포하지 않았습니다.

1. Node 24 단일 서버 또는 아래 Docker 이미지로 실행합니다. 운영용 `DATA_DIR`는 Google Drive·네트워크 공유 폴더가 아닌 **영구 로컬 디스크**에 지정합니다. SQLite DB를 여러 컴퓨터에서 동시에 열거나 실행 중인 파일을 동기화하지 마세요.
2. 운영 비밀정보는 서버의 환경변수/비밀정보 설정에 주입합니다. `NODE_ENV=production`, `HOST=0.0.0.0`, `APP_ORIGIN=https://실제도메인`을 설정합니다.
3. Caddy/nginx 등 HTTPS 리버스 프록시 뒤에서 실행하고 서버 포트는 프록시에서만 접근하도록 합니다. 앱에서 들어온 `X-Forwarded-For`를 무조건 신뢰하지 않기 때문에 프록시 환경의 로그인 IP 제한은 해당 프록시 단위로 적용됩니다. 대규모 운영 시 프록시 자체 요청 제한을 함께 설정하세요.
4. 실제 도메인을 Maps의 허용 URL에 등록하고 두 API 연결·로그인·저장·모바일을 재검증합니다.
5. 서버 재시작 시 같은 데이터 볼륨을 연결합니다. 백업은 서버를 정지한 상태에서 데이터 디렉토리 전체를 복사하거나 SQLite backup API를 사용합니다. 암호 해시와 세션 정보가 포함되므로 백업도 비공개로 관리합니다.

```sh
docker build -t walkmap:local .
docker run --name walkmap --env-file .env.production \
  -v walkmap-data:/data -p 127.0.0.1:3000:3000 walkmap:local
# 별도 터미널에서 계정을 추가합니다.
docker exec -it walkmap node manage.mjs add-user myname
```

컨테이너 파일은 준비했으나 이 환경에서 Docker 빌드/운영 HTTPS 배포는 실행하지 않았습니다. 실행 명령에 비밀값을 직접 넣지 마세요. 소스는 GitHub `main` 브랜치에 보관하며 공개 배포는 별도 작업입니다.

## 범위 밖

자동 도보 길찾기, 다른 지도 제공사, 리뷰/사진/영업시간 수집, 이미지/PDF 출력, 위치 추적, 공동 편집, 공개 공유 링크는 포함하지 않습니다. 첨부 디렉토리와 지정 GitHub 저장소가 모두 비어 있어 재사용할 기존 구현·로그인 구조나 참고 이미지가 없었습니다.
